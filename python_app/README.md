# منظومة عين الصقر - برنامج التحكم في خطوط الإنتاج والفرز والتعبئة والمحاسبة
## Falcon Eye Agrobotic OS — Desktop Production & ERP Suite

تطبيق متكامل لسطح المكتب (Desktop Application) مصمم بلغة **Python** وبواجهة عصرية داكنة **CustomTkinter** مع قاعدة بيانات **SQLite3**.
المنظومة مصممة وفق معمارية برمجية معيارية (Modular Plugin-based Architecture) لإدارة والتحكم في **كافة عمليات الإنتاج والفرز والسيور والتعبئة والربط مع وحدات التحكم الصناعية (PLC)** مع التنبيه الذكي المخصص حسب نوع كل خط إنتاج ومحصول، والربط المحاسبي الكامل.

## 🎛️ موديولات المنظومة والتحكم الشامل في عمليات الإنتاج

### 1. معالج التهيئة الأولية والربط السهل (Initial Setup Wizard)
* عند تشغيل البرنامج لأول مرة، يُفتح المعالج لتخصيص المنظومة بالكامل بنقرة واحدة:
  * **تحديد نوع الإنتاج والمحصول:** (🍊 محطة موالح / 🍏 محطة تفاحيات مائي / 🌴 محطة فرز تمور / 🤖 تعبئة وروبوتات / 🌐 محطة شاملة).
  * **تحديد نمط التشغيل:** (نظام متكامل شامل / تحكم وسكادا فقط / محطة متعددة المحاصيل).
  * **الربط التلقائي بوحدات التحكم بنقرة واحدة (Auto-Detect):** دعم Modbus TCP (Ethernet)، أو Serial/RS485، أو كاميرات الرؤية IP Cameras، أو نمط المحاكاة الافتراضية للاختبار قبل التوصيل الفعلي.

### 2. التحكم في السيور والسرعة (Conveyor Belts & VFD Control)
* التحكم في سرعة السير (أكواب / قطع في الثانية) وعزم المحركات عبر الإنفرتر (Variable Frequency Drive - VFD).
* دعم أوامر التشغيل (Run)، الإيقاف الناعم (Soft Pause)، والتوقف الطارئ الفوري (E-STOP).

### 3. التحكم في عمليات الفرز وبوابات الطرد (Sorting & Ejection)
* تزامن فائق السرعة مع **إنكودر السير (Rotary Encoder)** لتحديد إحداثيات كل ثمرة بدقة ميليمترية.
* إطلاق نبضات فتح بوابات الطرد النيوماتيك (Solenoid Valves) في التوقيت والمللي ثانية الدقيقة لإسقاط الثمرة في مخرجها المخصص (تصدير 1، محلي 2، تالف/صناعي).

### 4. التحكم في عمليات التعبئة والروبوتات (Packaging & Robotics)
* مراقبة وتفعيل خلايا الروبوت دلتا (Delta Robot Pick & Place).
* إدارة كؤوس شفط الفاكيوم (Vacuum Pressure Monitoring) لضمان ثبات الثمار.
* مراقبة تلقيم الصواني الكرتونية التلقائي وحساسات اكتمال البالتات.

### 5. محرك التنبيهات المخصص حسب نوع الخط (Line-Specific Alert Engine)
* **خطوط الموالح:** تنبيهات هبوط ضغط هواء بوابات الطرد (< 5.8 Bar)، ضبابية عدسات الكاميرات بسبب غبار الشمع، انخفاض نسبة التصدير.
* **خطوط التفاحيات:** تنبيه ارتفاع درجة حرارة مياه التفريغ Flume (> 14°C)، رصد كدمات داخلية بالأشعة تحت الحمراء NIR، منسوب المياه.
* **خطوط التمور:** تنبيه انحراف الرطوبة عن 18-22%، قياس تركيز السكريات Brix، انفصال القشرة.
* **خطوط التعبئة:** تنبيه ضعف تفريغ شفاطات الروبوت، نفاد الصواني الكرتونية.

### 6. الربط مع وحدات التحكم الصناعية (PLC & Hardware Bridge)
* بروتوكول **Modbus TCP / IP عبر Ethernet** للربط مع Siemens S7-1200 / Schneider / Delta / Fatek.
* بروتوكول **Modbus RTU / Serial USB** لكروت الريليهات ودوائر الميكروكنترولر المحلية.
* شاشة مراقبة حية لجميع إشارات الدخل الرقمي (Digital Inputs DI) ومخارج التحكم (Digital Outputs DO) مع إمكانية إرسال نبضات اختبارية يدوية.

## 🧮 المعادلات الهندسية والمحاسبية المستخدمة

### 1. معادلة تزامن إنكودر السير وتوقيت بوابات الطرد:
$$\text{Delay Pulses} = \frac{\text{Distance to Gate (mm)}}{\text{Resolution (mm/pulse)}}$$
$$\text{Ejection Trigger Time (ms)} = \frac{\text{Distance (m)}}{\text{Conveyor Speed (m/s)}} \times 1000$$

### 2. معادلة الطاقة الإنتاجية اللحظية (Tons / Hour):
$$\text{Capacity (TPH)} = \frac{\text{Lanes Count} \times \text{Speed (Cups/sec)} \times 3600 \times \text{Avg Fruit Weight (kg)} \times \text{Filling Efficiency (\%)}}{1000}$$

### 3. معادلات المحاسبة وضريبة القيمة المضافة (VAT - 14%):
$$\text{Subtotal} = \sum_{i=1}^{n} (\text{Quantity}_i \times \text{UnitPrice}_i)$$
$$\text{VAT Amount (14\%)} = \text{Subtotal} \times 0.14$$
$$\text{Grand Total} = \text{Subtotal} + \text{VAT Amount}$$

### 4. تقييم المخزون وتكلفة البضاعة:
$$\text{Inventory Value} = \sum (\text{Stock Quantity} \times \text{Cost Price})$$

## 🚀 طريقة التثبيت والتشغيل على جهازك (How to Run)

### 1. تثبيت المتطلبات:
افتح موجه الأوامر (CMD أو Terminal) في مجلد المشروع، ثم نفذ:
```bash
pip install -r requirements.txt
```

### 2. تشغيل البرنامج:
```bash
python main.py
```
* سيفتح البرنامج مباشرة مع **معالج التهيئة والربط الأولي** لتحديد نوع محطتك وتأكيد اتصال وحدة التحكم بنقرة واحدة، ثم الدخول للوحة التحكم والمراقبة الشاملة.
